# Анализатор процента побед в игре Дота2

## Зачем нужен данный сайт?

Данный сайт поможет игрокам понимать силу героя, смотря на его процент побед в игре.
Отличия от других сайтов, показывающих данную информацию заключается в том, что на сайте показывается только процент побед, что позволит быстро посмотреть кого можно выбрать из сильных персонажей.

## Как пользоваться данным сайтом?

Для работы сайта нужно соблюдать структуру файлов, относительно друг друга:
Общая папка:(
  templates:(
    index.html)
  app.py)

Также вам нужно проверить наличие библиотек "flask" и "requests".

Если структура файлов соблюдена, то запускайте файл app.py и оставляйте рабочим, пока вам нужно чтобы работал сайт, после чего можете открывать index.html.

## Что использовалась для создания?

Для создания использовались html, python, а также библиотеки для python: flask и requests.
